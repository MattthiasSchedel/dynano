# Dynano

**Dynano** is a free macOS menu bar app that turns the MacBook notch into a live hub for system stats, media controls, calendar, Claude usage and animated desk pets.

This repository hosts **releases** and **issue tracking** for Dynano. The app itself is closed-source.

## Download

Get the latest signed and notarized build:

- **Website:** <https://matthiasschedel.com/tools/dynano>
- **Releases:** see the [Releases tab](../../releases) for every version, with checksums and changelogs.

Each `Dynano-X.Y.Z.dmg` is signed with an Apple Developer ID and notarized by Apple — Gatekeeper won't warn you.

## System requirements

- macOS 26.2 or later
- Apple Silicon or Intel

## Reporting bugs / requesting features

Open an issue using the templates in this repo. Please include:

- macOS version
- Dynano version (visible in the menu bar context menu)
- Steps to reproduce
